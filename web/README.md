# Web — Tajuna Rock Festival

Esta carpeta contiene el sitio web estático del Festival Tajuna Rock.

## Estructura

```
web/
├── index.html       # Página principal del festival
├── css/
│   └── style.css    # Estilos del sitio
├── js/
│   └── main.js      # JavaScript del sitio
└── img/
    └── README.md    # Carpeta para imágenes
```

## Cómo usar

Abre `index.html` directamente en tu navegador, o publícalo en cualquier servidor de archivos estáticos (GitHub Pages, Netlify, Apache, Nginx…).

### GitHub Pages

1. Ve a *Settings → Pages* en este repositorio.
2. En *Source*, selecciona la rama `main` y la carpeta `/web` (o `/docs`).
3. Guarda y espera unos segundos hasta que aparezca la URL publicada.
