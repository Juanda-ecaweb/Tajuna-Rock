# Archivos

Esta carpeta contiene los archivos descargables del Festival Tajuna Rock:

- **Programa / Cartel** — imágenes y PDF con la programación del festival
- **Prensa** — dossier de prensa, logos y fotografías oficiales
- **Acreditaciones** — formularios e información para medios y artistas
- **Normativa** — reglamento y condiciones de acceso al recinto

Añade aquí cualquier fichero que quieras poner a disposición del público o de los colaboradores.
