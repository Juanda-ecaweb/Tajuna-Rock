# Tajuna-Rock
Repositorio Festival Rock tajuña Rock

## Estructura del repositorio

```
Tajuna-Rock/
├── web/          # Zona web — sitio web estático del festival
│   ├── index.html
│   ├── css/
│   ├── js/
│   └── img/
└── archivos/     # Zona de archivos — descargas y materiales del festival
```

### Zona web (`web/`)

Contiene el sitio web del festival listo para publicar. Consulta [`web/README.md`](web/README.md) para instrucciones de despliegue.

### Zona de archivos (`archivos/`)

Carpeta para alojar ficheros descargables: programa, dossier de prensa, acreditaciones, etc. Consulta [`archivos/README.md`](archivos/README.md) para más detalles.
